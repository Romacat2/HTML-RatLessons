# 🐀 Встав літеру — Roma's Rat Games

Тренажер орфографії та пунктуації: учень вставляє пропущені літери, апострофи, коми та інші символи просто в текст речення. Статичний сайт, без бекенду, працює як PWA (можна встановити на телефон/десктоп і користуватись офлайн).

## Логіка тесту

- 3 життя (❤️❤️❤️), кожне речення з хоча б однією помилкою забирає одне
- Речення показується з пропусками як поля вводу прямо всередині тексту — решта символів незмінна
- Фокус автоматично переходить до наступного пропуску після вводу символу; Backspace на порожньому полі повертає фокус назад
- Enter або кнопка «Перевірити» звіряють усі пропуски речення одразу
- При правильній відповіді — коротке ✅ (0.7с) і дощ з 🐀 (анімація, що поважає `prefers-reduced-motion`)
- При неправильній — ❌ з підсвіткою вірних/невірних полів (1.3с)
- Тест закінчується, коли вичерпані життя або пройдені всі речення уроку → перехід на результат

## Формат пропуску

Пропуском може бути будь-який символ — літера, апостроф, кома, знак оклику тощо. Якщо позначений символ — пробіл (наприклад, щоб перевірити, чи учень НЕ поставить зайвий апостроф), правильною відповіддю вважається порожній ввід.

## Редактор уроків

Вчитель вводить речення звичайним текстом, а нижче — розкладка з усіх символів речення у вигляді кнопок. Клік по символу позначає/знімає позначку «це пропуск» (підсвічується зеленим). Під розкладкою — живий перегляд речення з пропусками, показаними як `_`.

⚠️ Зміна довжини тексту речення (додавання/видалення символів) скидає всі позначені пропуски — індекси символів зсуваються, і стара розмітка стає невірною. Спершу доопрацюй текст речення, потім розставляй пропуски.

## Дані

Уроки зберігаються в `localStorage` під ключем `spelling-app:lessons`, окремо від уроків-флешкарток (`lessons-app:lessons`), бо структура даних інша: речення + індекси пропусків замість питання + варіантів відповіді.
