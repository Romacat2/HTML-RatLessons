# 🐀 Табличка множення — Roma's Rat Games

Тестер на швидкість множення з трьома життями. Статичний сайт, без бекенду, працює як PWA (можна встановити на телефон/десктоп і користуватись офлайн).

## Логіка тесту

- 3 життя (❤️❤️❤️), кожна неправильна відповідь забирає одне
- При правильній відповіді — коротке ✅ (0.5с) і дощ з 🐀 (анімація, що поважає `prefers-reduced-motion`)
- При неправильній — ❌ з показом правильної відповіді (1.1с)
- Тест закінчується, коли вичерпані життя або закінчився таймер на 60 секунд → перехід на на результат
- Ввід працює і з екранної клавіатури, і з фізичної (цифри, Backspace, Enter)
