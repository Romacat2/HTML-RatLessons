# 🐀 Табличка множення — Roma's Rat Games

Тестер на швидкість множення з трьома життями. Статичний сайт, без бекенду, працює як PWA (можна встановити на телефон/десктоп і користуватись офлайн).

## Як це влаштовано

```
index.html      — вибір рівня складності (легкий / середній / важкий)
test.html        — сам тест: 3 життя, приклад A × B, клавіатура 4×3
test.js          — логіка тесту: генерація прикладів, перевірка, дощ з 🐀
result.html       — результат: кількість правильних, час, кнопки заново/на головну

style.css         — спільні стилі (тема, кнопки, навігація)
nav.js            — перемикач теми (темна/світла), збережена в sessionStorage

manifest.json      — PWA-маніфест (назва, іконки, standalone-режим)
service-worker.js    — офлайн-кешування всіх файлів застосунку
register-sw.js      — реєстрація service worker, підключена на кожній сторінці
icons/            — іконки застосунку (192/512, maskable, apple-touch, favicon)
```

## Рівні складності

Передаються через query-параметр: `test.html?level=easy|medium|hard`

| Рівень | Діапазон множників |
|---|---|
| `easy` | 1–5 |
| `medium` | 2–10 |
| `hard` | 2–12 |

## Логіка тесту

- 3 життя (❤️❤️❤️), кожна неправильна відповідь забирає одне
- При правильній відповіді — коротке ✅ (0.5с) і дощ з 🐀 (анімація, що поважає `prefers-reduced-motion`)
- При неправильній — ❌ з показом правильної відповіді (1.1с)
- Тест закінчується, коли вичерпані життя → перехід на `result.html`
- Ввід працює і з екранної клавіатури, і з фізичної (цифри, Backspace, Enter)

## Деплой на GitHub Pages

1. Заливаєш увесь вміст цієї папки в репозиторій (корінь або `/docs`)
2. Settings → Pages → обираєш гілку/папку
3. Усе готово — шляхи в `manifest.json` і `service-worker.js` відносні, тож коректно працюють і в корені домену, і в піддиректорії (`username.github.io/repo-name/`)

**Важливо:** якщо після деплою правиш файли, підніми номер версії в `service-worker.js`:
```js
const CACHE_NAME = "rat-multiplication-v1"; // → v2, v3, ...
```
Інакше люди, що вже встановили PWA, бачитимуть закешовану стару версію.

## Локальний запуск

Будь-який статичний сервер підійде, наприклад:
```bash
python3 -m http.server 8000
```
Відкрити `http://localhost:8000/index.html`. Просто відкрити файл подвійним кліком (`file://`) теж працює, окрім service worker — він вимагає HTTP(S).
