# 📘 Уроки — Roma's Rat Games

Конструктор уроків-флешкарток із вибором варіантів відповіді. Вчитель створює урок у редакторі (питання + 3 варіанти, кожен текст або картинка), учень проходить його у форматі швидкого тесту з трьома життями. Усі уроки зберігаються локально в браузері (`localStorage`) — бекенд не потрібен.

## Як це влаштовано

```
index.html      — карусель уроків: старт / редагувати / видалити, картка "+" створює новий
editor.html       — редактор уроку: назва + список вправ (питання і 3 варіанти відповіді)
test.html        — проходження уроку: 3 життя, вибір з 3 варіантів
test.js          — логіка тесту: перемішування вправ і варіантів, перевірка, дощ з 🐀
result.html       — результат: правильні відповіді, помилки, час

lessons.js        — увесь шар зберігання уроків (CRUD у localStorage)
style.css         — спільні стилі (тема, кнопки, навігація)
nav.js            — перемикач теми (темна/світла)

manifest.json      — PWA-маніфест
service-worker.js    — офлайн-кешування файлів застосунку (картинки уроків НЕ кешує — вони на чужих доменах)
register-sw.js      — реєстрація service worker
icons/            — іконки застосунку
```

## Формат уроку

Зберігається в `localStorage` під ключем `lessons-app:lessons`, масив об'єктів:

```js
{
  id: "lesson_...",
  title: "Тварини",
  exercises: [
    {
      question: "cat",              // текст або URL картинки
      options: [
        { value: "кіт", correct: true },
        { value: "собака", correct: false },
        { value: "кінь", correct: false }
      ]
    },
    // ...
  ]
}
```

**Текст чи картинка визначається автоматично**: якщо значення починається з `http://` або `https://` — рендериться як `<img>`, інакше як текст. Це стосується і питання, і кожного з трьох варіантів незалежно — можна зробити "картинка → 3 текстових варіанти", "текст → 3 картинки-варіанти" чи будь-яку іншу комбінацію.

## Редактор (`editor.html`)

- Кожна вправа: 1 питання + 3 варіанти, вчитель вручну позначає, який варіант правильний (radio-кнопка)
- Валідація перед збереженням: назва уроку не порожня, усі поля вправ заповнені, у кожній вправі позначено рівно один правильний варіант
- Якщо передати `?lesson=<id>` — відкриває існуючий урок на редагування (копія даних, зміни не зберігаються, поки не натиснути "Зберегти")

## Логіка тесту (`test.html` + `test.js`)

- Вправи уроку перемішуються випадково при старті; варіанти відповідей всередині кожної вправи — теж
- 3 життя, та сама механіка, що й у табличці множення
- Тест завершується **у двох випадках**: вичерпані життя, або пройдені всі вправи уроку (без цього був би нескінченний цикл)
- На `result.html` передаються: кількість правильних, кількість помилок, загальний час
- Якщо URL картинки не завантажується — показується текстове повідомлення замість поламаної верстки

### Нюанс верстки з картинками

`.question-img` і кнопки `.option-btn` використовують flex-розподіл простору, де:
- **Кнопки варіантів** мають гарантований мінімум (`flex: 0 0 auto` на `.options-wrap`, `min-height: 2.6em` на кожній кнопці) — ніколи не стискаються до нечитабельного стану
- **Картинка питання** отримує весь залишок вертикального простору (`flex: 1 1 0` на `.question-img`) — росте і стискається під нього, зберігаючи пропорції (`object-fit: contain`)

Якщо колись знадобиться міняти розміри — починай з `.option-btn` (гарантований мінімум), а не з картинки, інакше вони знову почнуть конкурувати за простір непередбачувано.

## Деплой на GitHub Pages

Так само, як і решта проєктів цього набору — заливаєш вміст папки, вмикаєш Pages. Шляхи відносні, працює і в корені домену, і в піддиректорії.

**Підняти версію кешу** при кожному релізі зі змінами:
```js
// service-worker.js
const CACHE_NAME = "rat-lessons-v1"; // → v2, v3, ...
```

## Обмеження, про які варто знати

- **Уроки прив'язані до браузера/пристрою.** `localStorage` не синхронізується між пристроями — урок, створений на одному телефоні, не з'явиться на іншому. Для шкільного використання це означає: один учень/клас — один пристрій, або вчитель пересилає `lessons.js`-експорт вручну (наразі імпорту/експорту немає, можна додати пізніше).
- **Картинки — лише за зовнішнім URL.** Немає завантаження файлів чи вставки base64; вчитель повинен мати пряме посилання на зображення, доступне з інтернету.
- **Немає ліміту на кількість уроків** окрім самого ліміту `localStorage` (зазвичай ~5–10MB на домен) — для текстових даних цього вистачить на сотні уроків.

## Локальний запуск

```bash
python3 -m http.server 8000
```
Відкрити `http://localhost:8000/index.html`.
