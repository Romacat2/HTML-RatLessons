# 📘 Уроки — Roma's Rat Games

Конструктор уроків-флешкарток із вибором варіантів відповіді. Вчитель створює урок у редакторі (питання + 3 варіанти, кожен текст або картинка), учень проходить його у форматі швидкого тесту з трьома життями. Усі уроки зберігаються локально в браузері (`localStorage`) — бекенд не потрібен.

## Формат уроку

Зберігається в `localStorage` під ключем `lessons-app:lessons`, масив об'єктів:

```js
{
  id: "lesson_...",
  title: "Тварини",
  exercises: [
    {
      question: "cat",              // текст або URL картинки
      options: [
        { value: "кіт", correct: true },
        { value: "собака", correct: false },
        { value: "кінь", correct: false }
      ]
    },
    // ...
  ]
}
```

## Обмеження, про які варто знати

- **Уроки прив'язані до браузера/пристрою.** `localStorage` не синхронізується між пристроями — урок, створений на одному телефоні, не з'явиться на іншому. Для шкільного використання це означає: один учень/клас — один пристрій, або вчитель пересилає `lessons.js`-експорт вручну (наразі імпорту/експорту немає, можна додати пізніше).
- **Картинки — лише за зовнішнім URL.** Немає кешу файлів заради зменшення розміру сховище; вчитель повинен мати пряме посилання на зображення, доступне з інтернету.
- **Немає ліміту на кількість уроків** окрім самого ліміту `localStorage` (зазвичай ~5–10MB на домен) — для текстових даних цього вистачить на сотні уроків.
